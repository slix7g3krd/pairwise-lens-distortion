# pairwise-lens-distortion

广角镜头在画面边缘把直线拉成弧线，畸变模型只用了径向 k1，切向项缺失导致角落偏移方向不对；色差按固定像素偏移采样 RGB，分辨率切换后红蓝边宽度不变；暗角用屏幕空间半径，宽银幕裁切后四角亮度不对称；畸变在 HDR 色调映射之后做，边缘高光被二次压缩；UI 和字幕跟着场景一起畸变，文字边缘弯曲；多相机分屏共用一组畸变参数，左右眼画面在接缝处错位；后处理顺序把 bloom 放在畸变前，光源拖尾被拉成弧形；镜头脏污贴图用世界 UV，相机旋转时污渍跟着转；畸变反变换在 VR 双目下迭代次数不足，边缘采样越界回绕；性能档降级跳过色差，画面突然变干净。render/lens_distortion.py 是核心，tests/test_lens_distortion.py 15个红。要修的是：径向加切向畸变；色差偏移按分辨率缩放；暗角按裁切后画幅重算；畸变放在 HDR 线性域；UI 走独立 pass；多相机独立参数；bloom 在畸变前完成；脏污用屏幕空间；反变换迭代到收敛并钳制；降级保留色差。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
